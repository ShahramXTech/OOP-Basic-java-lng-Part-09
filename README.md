## Overview

This repository contains Java lab exercises focused on graphical user interface (GUI) development using Java Swing. The programs demonstrate how to create desktop application windows, organize interface components, and design basic forms using different layout managers.

These exercises are part of my university coursework and provide practical experience with Java GUI programming and object-oriented development concepts.

## Lab Contents

### 1. Basic Calculator Interface

* Create a GUI window using `JFrame`.
* Add labels and text fields for number input.
* Arrange arithmetic operation buttons.
* Use `GridLayout` to organize components.

### 2. Student Information Form

* Design a basic form with first and last name fields.
* Add Submit, Clear, Exit, and Help buttons.
* Organize components using `JPanel` and `BorderLayout`.

### 3. Simple Form Design

* Create a desktop form using Java Swing.
* Add text fields for personal information.
* Arrange Submit, Clear, Reset, Exit, and Help buttons.
* Apply `GridLayout`, `FlowLayout`, and `BorderLayout`.

## Technologies Used

* Java
* Java Swing
* AWT
* JFrame and JPanel
* Layout Managers

## Learning Objectives

* Understand the fundamentals of Java GUI programming.
* Create and configure application windows.
* Work with labels, text fields, and buttons.
* Organize components using layout managers.
* Develop practical desktop interface design skills.

## How to Run

1. Install the Java Development Kit (JDK).
2. Open the Java source file in your IDE.
3. Compile and run the program.
4. Interact with the displayed GUI.

**Note:** These exercises focus on interface design. Some buttons are visual components and may not have functional event handling.
